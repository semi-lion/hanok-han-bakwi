한국어 TTS 모델 비교

만 4~6세 아이에게 읽어주는 톤 기준: 유치원 선생님이나 박물관 해설사가 아이에게 설명하듯, 또렷하고 차분하게, 조금 느리게. 같은 문장 3개를 모델별로 들어보세요.

Qwen3-TTS (Sohee, CustomVoice)

라이선스: Qwen 모델 라이선스 · 특징: 앱에 실제 쓰이는 목소리, 커스텀 보이스 프롬프트 방식

1. "아궁이."
2. "여기에 불을 때면 밥도 짓고, 방도 따뜻해져요."
3. "창호지 문. 나무 틀에 얇은 종이를 발라서 만든 문이에요."

edge-tts (ko-KR-SunHiNeural)

라이선스: 마이크로소프트 Azure 음성 서비스를 무료로 우회 호출하는 비공식 API — 서비스 약관상 회색 지대, 상용 배포에는 권장하지 않음 · 특징: 속도 -10%, 자연스러운 여성 성우 톤

1. "아궁이."
2. "여기에 불을 때면 밥도 짓고, 방도 따뜻해져요."
3. "창호지 문. 나무 틀에 얇은 종이를 발라서 만든 문이에요."
edge-tts (ko-KR-JiMinNeural) — 스킵. 현재 edge-tts가 제공하는 ko-KR 목소리 목록에 더 이상 JiMin이 없음(SunHi · InJoon · HyunsuMultilingual만 확인됨).

Chatterbox Multilingual (기본 목소리, ko)

라이선스: MIT (Resemble AI) · 특징: 기본 프롬프트 목소리, 은은한 워터마크 내장(Perth)

1. "아궁이."
2. "여기에 불을 때면 밥도 짓고, 방도 따뜻해져요."
3. "창호지 문. 나무 틀에 얇은 종이를 발라서 만든 문이에요."

Chatterbox Multilingual (Sohee 클론)

라이선스: MIT (Resemble AI) · 특징: gamasot-say-0.mp3를 레퍼런스로 목소리 복제, 제로샷 클로닝 품질 확인용

1. "아궁이."
2. "여기에 불을 때면 밥도 짓고, 방도 따뜻해져요."
3. "창호지 문. 나무 틀에 얇은 종이를 발라서 만든 문이에요."
MeloTTS-Korean (MIT) — 스킵. 한국어 경로가 mecab-python3(일본어 모듈이 무조건 요구)와 python-mecab-ko(한국어 g2p가 요구)를 동시에 설치해야 하는데, 두 패키지가 같은 MeCab/ 네임스페이스를 덮어써서 한쪽을 설치하면 다른 쪽이 깨지는 충돌이 있음. 이 venv에서는 우회하지 못해 시간 예산 안에 포기.
CosyVoice2-0.5B (Apache) — 스킵. 남은 작업 시간 안에 설치·검증까지 마치기 어려워 보류(설치 자체를 시도하지 않음). 필요하면 별도 세션에서 이어서 진행 권장.

생성: tools/compare/make-samples.py · 오디오는 22kHz 모노, ffmpeg astats로 피크를 측정해 -1dBFS로 정규화(Qwen3 기존 클립 제외, 재생성 금지 원본 그대로 사용).
